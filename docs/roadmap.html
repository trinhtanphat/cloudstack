Roadmap & trạng thái

Tổng hợp các hạng mục triển khai cho VNSO CloudStack. Trạng thái: Done · WIP · Planned.

✅ Đã hoàn tất (Done)

  • ✓Compute đa hypervisor: KVM, VMware, XenServer/XCP-ng, Hyper-V, Baremetal, UCS.
  • ✓GPU Cloud Service (passthrough & vGPU NVIDIA, telemetry, quota theo project).
  • ✓Database-as-a-Service: MySQL/PostgreSQL/MongoDB/Redis với HA + backup + monitor.
  • ✓Service Catalog với batch tracker, auto-focus, toast, clipboard copy, i18n vi/en.
  • ✓Bulk operations triển khai 1000+ VM/dịch vụ song song có retry & rollback.
  • ✓22 GCP service connectors (xem trang GCP Integrations).
  • ✓Kubernetes Service (CKS): create / scale / upgrade / autoscaler.
  • ✓HA Management server cluster + MySQL InnoDB cluster, NFS/Ceph primary, replicated secondary.
  • ✓Bảo mật: HSTS, CSP, X-Frame, RBAC, API key rotation, OWASP Top-10 hardening.
  • ✓Quan sát hệ thống: Prometheus exporter, dashboard health, alert handlers (SNMP/Syslog).
  • ✓Quota & Billing tariff theo tài nguyên, usage report, balance.
  • ✓Web UI Vue 3 (i18n vi/en) + CLI cmk + REST/Query API + SDK Python & cloud-cli.
  • ✓VNSO scripts: run-functional-smoke.sh, run-platform-quality-gates.sh, run-pentest-baseline.sh.
  • ✓GitHub Actions: GPU service PR workflow + VNSO quality gates workflow.
  • ✓Tài liệu HTML landing pages (Tổng quan, Tính năng, Catalog, Kiến trúc, GCP, Vận hành, Roadmap) — light/dark mode AA.
  • ✓Runbook ổn định Zone-2, plan triển khai 3-server & 4-server.
  • ✓Service Catalog Go/No-Go template & index tài liệu VNSO.
