Plugins (in plugins/integrations/):
  gpu-service, dbaas-service, bulk-service, service-catalog,
  gcp-services, kubernetes-service, prometheus, cloudian

Backend (Java / Spring)

  • Management Server: orchestration, API endpoint, async job manager.
  • Engine modules: engine/orchestration, engine/schema, engine/storage, engine/network.
  • Plugins: nạp qua Spring context tại plugins/integrations/{name}/src/main/resources/META-INF/cloudstack/.
  • SystemVM: virtual router, secondary storage VM, console proxy. Metadata bundle ở /usr/share/cloudstack-management/templates/systemvm/.

Frontend (Vue 3 + Vite)

  • Cấu hình section: ui/src/config/section/*.js, plugin UI: ui/src/config/section/plugin/*.js.
  • Component theo plugin: ui/src/views/plugins/{gpu,dbaas,bulkops,catalog}/.
  • i18n: vi + en (locale gốc Apache giữ nguyên, thêm bản dịch VNSO).
  • Dark/Light mode: chuyển nhanh; tương phản đạt WCAG AA cho text chính.

Multi-zoneNMỗi zone có pod/cluster riêng; secondary storage replicated.

Luồng API

  1. Client (UI/CLI/SDK) gọi REST /client/api?command=...&apikey=...&signature=....
  2. Nginx kiểm tra TLS + security headers, forward tới Management Server.
  3. Management Server xác thực API key/signature, phân quyền RBAC.
  4. Tạo async job (nếu cần), trả về jobid; client poll queryAsyncJobResult.
  5. Job được resource manager xử lý: gọi hypervisor agent, tạo entries DB, cập nhật usage.
