Nền tảng IaaS doanh nghiệp dựa trên Apache CloudStack

VNSO CloudStack là bản phân phối thương mại hoá của Apache CloudStack, bổ sung GPU-as-a-Service, Database-as-a-Service, Bulk Operations, Service Catalog, tích hợp GCP và bộ công cụ vận hành/bảo mật cho môi trường multi-zone, HA.

Xem tính năng → Kiến trúc Vận hành

Điểm nổi bật

GA

Compute đa hypervisor

KVM, VMware vSphere, XenServer/XCP-ng, Hyper-V, LXC. Orchestration multi-zone, multi-pod, multi-cluster.

GA

GPU Cloud Service

Khởi tạo VM GPU NVIDIA (A100/H100/L40S/RTX), passthrough & vGPU, telemetry và quota theo project.

GA

Database-as-a-Service

MySQL, PostgreSQL, MongoDB, Redis với backup/restore, snapshot, monitoring và HA replica.

GA

Service Catalog

Khởi tạo workload theo template (EC2-like, MySQL, MongoDB, S3) với batch tracker và clipboard helper.

GA

Bulk Operations

Triển khai 1000+ VM/dịch vụ song song, theo dõi tiến trình, retry và rollback.

Beta

GCP Integrations

22 GCP service connectors: GCE, GKE, GCS, BigQuery, Cloud SQL, Pub/Sub, IAM, ... cho hybrid cloud.

GA

Kubernetes Service

CKS clusters: tạo, scale, upgrade, autoscaler, hỗ trợ network policy & storage class.

GA

HA & Multi-Zone

Management server cluster + MySQL InnoDB cluster, NFS/Ceph primary, replicated secondary, fail-over zone.

GA

Bảo mật & Compliance

HSTS, CSP, X-Frame, RBAC, API key rotation, pentest baseline, OWASP Top-10 hardening.

GA

Quota & Billing

Tariff theo tài nguyên, usage report, balance, gắn được với hệ thống billing ngoài.

GA

Quan sát hệ thống

Tích hợp Prometheus exporter, dashboard health, alerts, và VNSO monitoring scripts.

GA

Đa nền tảng client

Web UI Vue 3, Mobile (Capacitor), Desktop (Electron), Browser Extension (MV3), CLI cmk, Python SDK, cloud-cli — chi tiết ở Clients.

Bắt đầu nhanh

1. Triển khai bằng Docker

Dùng docker-compose.prod.yml để chạy management + MySQL + UI. Xem docker/ và DOCKER_SETUP.md.

2. Triển khai 3-server (Production)

Theo THREE-SERVER-DEPLOYMENT-PLAN.md và DEPLOYMENT-RUNBOOK-4-SERVERS.md.

3. Vận hành & smoke test

Chạy scripts/vnso/run-functional-smoke.sh, run-platform-quality-gates.sh, run-pentest-baseline.sh.

4. Bulk & Catalog

Xem Bulk 1000 EC2 guide và Service Catalog Go/No-Go.
