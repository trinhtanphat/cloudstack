Vận hành, HA, Hiệu năng & Bảo mật

High Availability

  • Management cluster: ≥ 2 node Tomcat, dùng VIP/Keepalived hoặc external LB.
  • MySQL HA: InnoDB Cluster (Group Replication) hoặc Galera; thiết lập db.ha.enabled=true.
  • SystemVM HA: tự động tái tạo VR/SSVM/CPVM khi mất; theo dõi qua scripts/vnso/cleanup-mshost-stale.sh.
  • VM HA: bật ha.enabled trên service offering; KVM HA dựa trên fencing libvirt.
  • Storage HA: NFS multi-path, Ceph RBD replica ≥3, secondary có thể replicate cross-zone.

Load Balancing

  • Tầng UI/API: Nginx (đã cấu hình HSTS, CSP, X-Frame) hoặc HAProxy trước các management node.
  • Tầng tenant: Virtual Router (HAProxy), Netscaler, F5, hoặc internal LB.
  • Health check: /client/static/config.json hoặc /client/api?command=listCapabilities.
  • Sticky sessions: bật source IP / cookie cho UI, không bắt buộc cho API.

Bảo mật (đã hardening)

  • TLS 1.2+ với HSTS (max-age=31536000; includeSubDomains; preload).
  • CSP: default-src 'self', font/style/script restrict; cấu hình ở nginx.conf.
  • Headers: X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin, Permissions-Policy giới hạn camera/mic/geolocation.
  • RBAC: Domain → Account → User; role và API permission per-section.
  • API key rotation: scripts/vnso/rotate-admin-api-key.sh; lưu trong bảng api_keypair.
  • Pentest baseline: scripts/vnso/run-pentest-baseline.sh chạy ZAP baseline + nikto.
  • OWASP Top 10: A01 (RBAC), A02 (TLS+HSTS), A03 (parameterized SQL), A05 (security headers), A07 (signed API), A09 (audit log), A10 (no SSRF trong management API).
  • Audit: cloud.event + log Tomcat; chuyển ELK/Loki cho long-term.

Monitoring & Quan sát

  • Prometheus exporter (plugin) + Grafana dashboard cho VM/host/zone.
  • scripts/vnso/run-monitoring-check.sh: cron health check, gửi alert.
  • Dashboard health UI: status các zone, pod, cluster, host.
  • Log: management-server.log, vmops.log, agent.log; rotate qua logrotate.

Quality Gates & CI

  • scripts/vnso/run-platform-quality-gates.sh — gom build, lint, unit, smoke.
  • scripts/vnso/run-functional-smoke.sh — đăng nhập, list zone/host/VM, deploy 1 VM thử.
  • GitHub Actions: .github/workflows/ bao gồm GPU PR và VNSO quality gates.

Disaster Recovery

  • Snapshot MySQL theo lịch (xtrabackup) → object storage.
  • Secondary storage: replica cross-zone hoặc rclone sync sang S3.
  • Runbook khôi phục: Zone-2 Stabilization Runbook.

Quy trình vận hành hằng ngày

  1. Sáng: kiểm tra run-monitoring-check.sh, dashboard health, capacity zone.
  2. Theo dõi job queue (async_job) — fail rate < 1%.
  3. Tuần: chạy run-platform-quality-gates.sh + run-pentest-baseline.sh.
  4. Tháng: rotate API key admin, kiểm thử restore backup MySQL ở môi trường staging.
