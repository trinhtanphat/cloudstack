Bảo mật & Compliance

Mặc định bật ON cho mọi triển khai production.

Lớp mạng & HTTP

  • TLS 1.2+ tại Nginx; HSTS max-age=63072000; includeSubDomains; preload.
  • Rate-limit per-IP cho /client/api (30 r/s burst 60) và /client/api/login (5 r/s burst 10) — chống credential stuffing/DoS.
  • Cấu hình mẫu: scripts/vnso/nginx/vnso-cloudstack-hardening.conf, vnso-cloudstack-headers.inc, vnso-cloudstack-locations.example.conf.

Xác thực & phân quyền

  • API key + HMAC-SHA1 signature, phân định trong bảng api_keypair.
  • RBAC: Domain → Account → User; Role-based API permission per-section.
  • 2FA: TOTP plugin (built-in) — bật ở user profile.
  • SSO: SAML2 / OAuth2 plugin sẵn có (xem plugins/user-authenticators).
  • Rotation: scripts/vnso/rotate-admin-api-key.sh (đã sẵn lịch crontab mẫu).

Pentest & Compliance Automation

  • scripts/vnso/run-pentest-baseline.sh: ZAP baseline + nikto scan UI + API.
  • scripts/vnso/run-platform-quality-gates.sh: gom build, lint, smoke, license, SCA.
  • scripts/vnso/run-monitoring-check.sh: cron health + alert manager bridge.
  • Báo cáo lỗ hổng: theo dõi qua cloudstack.apache.org/security.

Hardening checklist trước go-live

  1. Đổi mật khẩu admin gốc, vô hiệu hoá user mặc định không dùng.
  2. Bật TLS với chứng chỉ tin cậy; đặt client.protocol=https.
  3. Apply 3 file nginx ở scripts/vnso/nginx/ — kiểm tra bằng securityheaders.com.
  4. Tạo role least-privilege; tránh dùng root admin cho automation.
  5. Bật 2FA cho mọi tài khoản admin; bật SSO khi có IdP.
  6. Lập lịch rotate-admin-api-key.sh ≥ 90 ngày/lần.
  7. Replicate audit log sang ELK/Loki, retention ≥ 365 ngày.
  8. Chạy run-pentest-baseline.sh ở staging; sửa mọi finding HIGH.
  9. Test DR: restore MySQL backup & secondary storage ở env staging hằng tháng.
