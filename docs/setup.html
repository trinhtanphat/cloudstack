1. Yêu cầu hệ thống
  • Management server: 8 vCPU / 16 GB RAM / 100 GB SSD; Ubuntu 22.04 hoặc Rocky 9.
  • MySQL: 8 vCPU / 32 GB RAM / 500 GB NVMe (cluster 3 node nếu HA).
  • Hypervisor KVM: 16+ vCPU / 64+ GB RAM, NIC ≥ 10 Gbps, /var/lib/libvirt ≥ 200 GB.
  • Primary storage: NFS hoặc Ceph RBD (latency < 5 ms).
  • Secondary storage: NFS hoặc S3-compatible (Cloudian).
  • Mạng quản lý + storage tách VLAN; jumbo frame (MTU 9000) khuyến nghị.
2. Cài Management Server (Docker compose) 
cd /opt && git clone https://github.com/trinhtanphat/cloudstack.git
cd cloudstack && cp docker-compose.prod.yml docker-compose.yml
docker compose up -d
# Tài khoản admin mặc định: admin / Admin@@3224@@ (đổi ngay sau lần đầu đăng nhập)
docker compose logs -f management | tail -200

Triển khai 3-server / 4-server: xem THREE-SERVER-DEPLOYMENT-PLAN.md và DEPLOYMENT-RUNBOOK-4-SERVERS.md.

3. Khởi tạo MySQL InnoDB Cluster (HA) 
# Trên 3 node MySQL
mysqlsh --uri root@node1 -- dba configure-instance --interactive=false
mysqlsh --uri root@node1 -- dba create-cluster vnso \
  --adopt-from-gr=false --multi-primary=false
mysqlsh --uri root@node1 -- cluster add-instance node2 --recovery-method=clone
mysqlsh --uri root@node1 -- cluster add-instance node3 --recovery-method=clone

# Trên management node
sed -i 's/db.cloud.host=.*/db.cloud.host=mysql-router/' /etc/cloudstack/management/db.properties
systemctl restart cloudstack-management
4. Thêm host KVM 
apt install -y cloudstack-agent qemu-kvm libvirt-daemon-system
echo "host=mgmt.vnso.vn" >> /etc/cloudstack/agent/agent.properties
systemctl restart cloudstack-agent
# UI: Infrastructure → Hosts → Add Host → KVM → IP + root password
5. Tạo Zone / Pod / Cluster (Advanced networking)
  1. UI → Infrastructure → Zones → Add Zone.
  2. Chọn Advanced với security group hoặc Isolated.
  3. Nhập DNS, internal DNS, network domain.
  4. Khai báo physical network: management / public / guest / storage.
  5. Thêm Pod: gateway, netmask, IP range cho management.
  6. Thêm Cluster (KVM/VMware), gán host.
  7. Thêm Primary storage và Secondary storage.
  8. Bật zone — chờ SystemVM (SSVM, CPVM) lên trạng thái Running.
6. Cấu hình Primary/Secondary storage 
# Primary NFS:
mount -t nfs storage.vnso.vn:/export/primary /mnt/primary
# UI: Add Primary → Server: storage.vnso.vn → Path: /export/primary

# Secondary NFS:
mount -t nfs storage.vnso.vn:/export/secondary /mnt/secondary
# UI: Add Secondary → URL: nfs://storage.vnso.vn/export/secondary

Ceph RBD: tham khảo docs.cloudstack.apache.org; tạo pool riêng (replica 3) và import bằng UUID.

7. Cấu hình mạng (Isolated & VPC)
  1. Tạo Network Offering với LB + Firewall + Source NAT (VR-based).
  2. Account user → Network → Add Guest Network.
  3. VPC: chia tier (web/app/db), gắn ACL ingress/egress riêng.
  4. Site-to-site VPN: Network → VPN → Site-to-Site.
  5. Public IP & PF: Network → Public IPs → Configuration → Port Forwarding.
8. Deploy VM đầu tiên
  1. UI → Compute → Instances → Add Instance.
  2. Chọn template (Ubuntu/Rocky/Debian); chọn service offering.
  3. Chọn network; nhấn Launch VM.
  4. Khi state Running, lấy IP/console qua nút VNC.
  5. SSH: ssh root@<public-ip> (mật khẩu nhận trong tab Notifications).

10. Bật TLS & security headers 
# Sao chép snippet hardening
sudo cp scripts/vnso/nginx/vnso-cloudstack-hardening.conf  /etc/nginx/conf.d/
sudo cp scripts/vnso/nginx/vnso-cloudstack-headers.inc      /etc/nginx/conf.d/
sudo cp scripts/vnso/nginx/vnso-cloudstack-locations.example.conf \
        /etc/nginx/conf.d/vnso-cloudstack.conf

sudo certbot --nginx -d manage.example.vn -d docs-cloudstack.vnso.vn
sudo nginx -t && sudo systemctl reload nginx

Kiểm tra: securityheaders.com phải đạt ≥ A.

11. Build & cài Mobile (Android/iOS) 
cd mobile
npm install
VNSO_MGMT_URL=https://manage.example.vn npm run build:web
npx cap add android        # lần đầu
npx cap add ios            # lần đầu (chỉ macOS)
npm run sync
npm run open:android       # mở Android Studio
npm run open:ios           # mở Xcode

APK release tự build qua workflow release-clients.yml — xem CI/CD pipeline.

12. Build & cài Desktop 
cd desktop
npm install
npm start                 # chạy thử
npm run build:linux       # AppImage + deb
npm run build:mac         # dmg (chỉ macOS)
npm run build:win         # nsis (chỉ Windows)
13. Cài Browser Extension
  1. Mở chrome://extensions hoặc edge://extensions.
  2. Bật Developer mode.
  3. Nhấn Load unpacked → chọn thư mục extension/.
  4. Mở popup → Cấu hình → URL + API key/secret.

Phiên bản đóng gói chính thức: tải vnso-cloudstack-extension-*.zip ở GitHub Releases.

14. Phát hành bản client mới 
# 1. Bump version
jq '.version = "1.0.1"' desktop/package.json | sponge desktop/package.json
jq '.version = "1.0.1"' mobile/package.json  | sponge mobile/package.json
jq '.version = "1.0.1"' extension/manifest.json | sponge extension/manifest.json

# 2. Commit + tag
git commit -am "release: clients-v1.0.1"
git tag clients-v1.0.1
git push origin vnso clients-v1.0.1

# 3. Workflow .github/workflows/release-clients.yml chạy:
#    - Build desktop (Linux/macOS/Windows)
#    - Build Android APK (iOS IPA nếu IOS_BUILD_ENABLED=true)
#    - Build extension zip
#    - Build web UI tarball
#    - Tạo GitHub Release với tất cả artifact
