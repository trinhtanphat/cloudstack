Clients đa nền tảng

Mọi client dùng chung CloudStack REST API ký HMAC-SHA1, chia sẻ một tập credential.

GA

Web UI

Vue 3 + Vite, i18n vi/en, light/dark mode, sidebar GPU/DBaaS/BulkOps/Catalog. Build: cd ui && npm ci && npm run build.

GA

Mobile (Android & iOS)

Capacitor wrapper trong mobile/. WebView native ôm trọn UI, lưu credential qua Keychain/EncryptedSharedPreferences. Hỗ trợ push notification.

npm run build:web && npx cap add android && npm run sync

GA

Desktop (Linux/macOS/Windows)

Electron wrapper trong desktop/: contextIsolation, sandbox, CSP injection, chặn navigation cross-origin. Đóng gói AppImage/deb/dmg/nsis.

npm install && npm run build:linux

GA

Browser Extension (MV3)

Chrome/Edge popup: list VM, Start/Stop/Reboot, copy API URL, mở Service Catalog. Polling 5 phút thông báo VM Error. Source: extension/.

GA

CLI cmk

Apache CloudStack CLI gốc — interactive shell, scriptable. Cài qua pip install cloudmonkey.

GA

Python SDK

Trong python/; cung cấp client typed cho mọi command, dùng cho automation/CI.

GA

cloud-cli (Go)

CLI nhẹ trong cloud-cli/ — single binary, dùng tốt trong CI và air-gapped env.

GA

REST / Query API

Tất cả command có sẵn ở /client/api?command=...; kèm rate-limit per-IP qua Nginx (xem Bảo mật).

Cài đặt nhanh

Mobile

cd mobile
npm install
VNSO_MGMT_URL=https://manage.example.vn npm run build:web
npx cap add android        # lần đầu
npm run sync && npm run open:android

Desktop

cd desktop
npm install
npm start                  # chạy local
npm run build:linux        # đóng gói AppImage/deb

Browser Extension

  1. chrome://extensions → bật Developer mode.
  2. Nhấn Load unpacked → chọn thư mục extension/.
  3. Mở popup → Cấu hình → nhập URL + API key/secret.
