Cấu hình nhanh

# 1) Đặt service-account key cho CloudStack management
cloudmonkey set apikey ...
cloudmonkey set secretkey ...
# 2) Cấu hình project & credentials GCP qua global setting
cloudmonkey update configuration name=gcp.project.id value="my-vnso-project"
cloudmonkey update configuration name=gcp.credentials.path value="/etc/cloudstack/management/gcp-sa.json"

# 3) Liệt kê VM GCP
cloudmonkey list gcpinstances zoneid=<zone-uuid>

# 4) Tạo bucket GCS
cloudmonkey create gcpbucket name=vnso-cs-prod-logs location=ASIA-SOUTHEAST1 storageclass=STANDARD

Kịch bản hybrid điển hình

Burst-out compute

Khi quota local hết, tự động tạo VM tại GCE qua createGcpInstance, gắn vào VPN site-to-site đã có.

Backup off-site

Snapshot CloudStack → đẩy lên GCS bucket bằng createGcpBucket + lifecycle rule (Coldline / Archive).

Data lake unified

Đồng bộ dữ liệu từ DBaaS local sang BigQuery dataset (listGcpBigQueryDatasets) phục vụ phân tích.

AI inference

VM local gọi mô hình Gemini/Vertex qua listGcpGeminiModels + Vertex Notebook để fine-tune.

Quan sát tập trung

Đẩy log audit CloudStack lên Cloud Logging, query bằng listGcpLogEntries.

Disaster recovery

Replicate volume → GCS + tạo Cloud SQL replica từ MySQL local cho DR-as-a-Service.

Bảo mật

  • Khoá service-account lưu trên management server với chmod 0600; xoay vòng định kỳ.
  • Mọi gọi GCP đều log audit qua event-bus & alert-handlers.
  • Áp dụng least-privilege ở phía GCP IAM cho service account integration.
  • Network egress đi qua proxy đã được whitelist trong firewall VNSO.
